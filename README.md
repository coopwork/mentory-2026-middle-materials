## 🚀 Что будем изучать

| Раздел | Основные темы |
| --- | --- |
| 1. Advanced React | Rendering и reconciliation, React patterns, advanced hooks и архитектура state |
| 2. TypeScript Practical | Типизация компонентов и hooks, generics, utility types, DTO, validation и runtime safety |
| 3. Next.js App Router | Layouts, nested routes, route groups, состояния загрузки и ошибок, metadata и navigation |
| 4. Server Components | Границы client/server, hydration, data fetching, cache и revalidation |
| 5. Advanced Rendering | SSR, ISR, SSG, hybrid rendering, Suspense и streaming UI |
| 6. Auth & Security | Токены, cookies, protected routes, XSS/CSRF и приложение с системой ролей |
| 7. Feature-Sliced Design | Слои, public API, изоляция модулей, зависимости и декомпозиция |
| 8. Frontend Architecture | Масштабируемая архитектура, качество кода, технический долг и рефакторинг |
| 9. State, Realtime, Performance & Testing | Zustand, TanStack Query, React Hook Form, WebSocket, оптимизация, Vitest, React Testing Library и Playwright |
| 10. Multi-role Production Application + Career Block | Итоговое приложение, middle-интервью, system design, live coding и architecture review |

AI используется как инженерный инструмент: debugging, анализ архитектуры, рефакторинг, prompt и context engineering.

## 🛠 Практика и итоговый проект

В программе предусмотрены работы с dashboard UI, типизированными формами, контентными платформами, авторизацией и переработкой архитектуры. Конкретные задания и критерии проверки будут публиковаться по мере подготовки материалов.

**Team Production Project:** Next.js, SSR/ISR/SSG, авторизация и система ролей.

**Multi-role Production Application** — итоговый проект в формате SaaS dashboard, admin platform, analytics или collaboration platform.

Обязательный стек итоговой работы:

- Next.js и TypeScript.
- Feature-Sliced Design.
- Zustand и TanStack Query.
- Auth и role-based access.
- WebSocket.
- Testing.

В итоговой работе предусмотрены масштабируемая архитектура, SSR/ISR/SSG, оптимизация рендеринга, error boundaries и адаптивный интерфейс. Карьерный блок включает mock interviews, frontend system design, live coding и architecture review.
